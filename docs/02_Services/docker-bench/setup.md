# Docker Bench Setup

> [!NOTE]
> #DockerBench #Security #Docker


## 1. Description

Docker Bench for Security audits a Docker host against the CIS Docker Benchmark, flagging common misconfigurations in daemon, containers, and host setup.

## 2. Installation
Clone the repository:

   ```bash
   git clone https://github.com/docker/docker-bench-security.git
   ```

## 3. Usage
Run the audit:

   ```bash
   cd docker-bench-security
   sh docker-bench-security.sh
   ```
